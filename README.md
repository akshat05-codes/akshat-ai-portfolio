# Akshat Sharma — AI Portfolio

A responsive React + Vite portfolio website with a dark AI/data aesthetic, animated network hero, project visuals, skills, education and contact sections.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy without installing an app

1. Create a **public** GitHub repository named `akshat-ai-portfolio`.
2. On GitHub, choose **Add file → Upload files** and upload the project files.
3. Go to Vercel, sign in with GitHub, choose **Add New → Project**, and import the repository.
4. Vercel should detect Vite. Use `npm run build` as the build command and `dist` as the output directory if it asks.
5. Deploy. You will get a Vercel URL.
6. Add your custom domain later from the Vercel project settings.
